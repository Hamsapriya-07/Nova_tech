## 📌 Overview
**Nova Tech** is an interactive Web Administrative Dashboard prototype designed to streamline academic metrics, faculty views, and student records into a single responsive interface.

👉 **[🌐 View Live Demo Site](https://hamsapriya-07.github.io/Nova_tech/)**

---

## 🌟 Key Features

* 👨‍🏫 **Faculty Dashboard:** Context-aware views that update dynamic components based on department needs.
* 🎓 **Batch & Year Filtering:** Interactive selectors to filter student records across academic batches.
* 📱 **Responsive UI:** Utility-first styling designed for smooth cross-device compatibility.
